Memory Leak

The program creates memory but forgets to release it.
In long-running programs, leaked memory accumulates and wastes system resources.

Use-After-Free

The program tries to use memory after it has already released it.
Can cause crashes, data corruption, or security vulnerabilities.

Double Free

The program tries to release the same memory twice.
Corrupts heap metadata and can lead to exploitable vulnerabilities.

Buffer Overflow

The program tries to put more data into a memory area than it can safely hold.
One of the most common and dangerous security vulnerabilities.

Dangling Pointer

The program keeps a reference to memory that has already been released.
Causes subtle, hard-to-find bugs because they may appear to work correctly.
